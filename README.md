# career-ops personal data

Personal user-layer files for career-ops (CV, profile, scoring rules, job-board config, tracker, evaluation reports).

## Restore
1. `npx @santifer/career-ops init` (creates `./career-ops`)
2. Copy everything in this repo (except README.md and .git) into that `career-ops` folder, keeping the paths.
3. Run `node doctor.mjs` inside it.
